## Feature Details

### Free Version Features

#### Core Functionality
- **Plus/Minus Buttons**: Add quantity increment/decrement buttons to WooCommerce product pages
- **Universal Support**: Works on product pages, cart page, mini cart, and archive pages
- **Decimal Support**: Full support for decimal quantity values
- **Enable/Disable**: Global on/off switch for the plugin

#### Styling Options
- **Button Colors**: Customize background, border, and font colors
- **Hover Effects**: Set different colors for hover states
- **Border Control**: Adjust border width and radius
- **Input Box Styling**: Full control over input box appearance
- **Input Dimensions**: Set custom width and height for quantity input
- **Custom CSS**: Add your own CSS for advanced customization

### Premium Version Features

#### Advanced Button Icons
- **Multiple Icon Sets**: Choose from arrows (↑/↓), chevron, circle icons (⊕/⊖)
- **Custom Text/HTML**: Use custom text or HTML entities for buttons
- **Icon Flexibility**: Full control over button appearance

#### Button Animations
- **Pulse on Hover**: Subtle pulsing effect when hovering
- **Bounce on Click**: Bouncing animation when clicking buttons
- **Scale on Hover**: Smooth scaling effect on mouse hover
- **Rotate on Click**: Rotating animation for button clicks

#### Position Control
- **Vertical Layout**: Stack buttons vertically with input in the middle
- **Vertical Right**: Place buttons vertically on the right side
- **Reversed Layout**: Place plus button before minus (Plus - Input - Minus)
- **Flexible Positioning**: Full control over button arrangement

#### Advanced Styling
- **Box Shadow**: Add depth with customizable shadow effects
- **Transition Effects**: Control animation duration and easing
- **Enhanced Visuals**: Create unique, professional-looking quantity selectors

#### Premium Support
- **Priority Email Support**: Get faster responses to your questions
- **Dedicated Assistance**: Direct access to development team
- **Custom Solutions**: Help with specific customization needs
